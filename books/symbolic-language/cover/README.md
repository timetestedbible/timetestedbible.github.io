# MEAT cover assets

This directory owns the MEAT cover package.

`companion-ttt-front.png` is a local snapshot used only for the TTT promotion on MEAT jackets. MEAT cover sources must reference this snapshot rather than files in TTT's concept or production directories.

TTT cover sources live in `books/time-tested-tradition/cover/`. Cross-promotions use local snapshot files so changes to one book's cover cannot silently alter the other book's jacket.
