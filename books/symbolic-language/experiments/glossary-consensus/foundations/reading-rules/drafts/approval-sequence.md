# Human approval sequence

No draft becomes an experimental input merely because it exists in this
folder.

1. The user approves the exact canonical-premises document.
2. Providers independently propose rules under those premises.
3. The provider proposals are compared, but no author rules are submitted.
4. The user reviews and approves every material rule in the author draft.
5. Providers review only that exact approved rules hash, without its rationale.
6. Every requested clarification is returned to the user before any revision.
7. A revised rules draft is submitted only after the user approves its exact
   text.
8. After unanimous rules agreement, the user separately reviews and approves
   the rationale.
9. Only then is the rationale disclosed to providers.
10. A downstream baseline is created only after both gates pass unanimously.

Earlier rules-v1, rules-v2, and rules-v3 files are discussion history, not
approved inputs or baselines.
